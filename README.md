# Portfolio: Rasel Ur Rahman

## Update content
Open `script.js` and edit only the `DATA` block at the top.
- Photo: replace `assets/profile.png`
- Lab photos: put images in `assets/lab/`, add file names to `images: []`
- Project screenshots: `assets/projects/`, set `image`, `github`, `live`
- Certificates: `assets/certificates/`, set `image` (and `link` to verify)

## Publish on GitHub Pages
1. Upload all files to your repo (`Protfolio-website`), keep the folder structure.
2. Settings > Pages > Deploy from branch > `main` / root.
3. Site: https://raselurrahman0.github.io/Protfolio-website/
